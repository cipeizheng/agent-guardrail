# 检测组件特性评估

本目录记录检测器在固定语料上的分类表现。代码和配置中的 `Detector` 指负责产生检测结果的组件；这里的评估结果用于描述组件行为，不代表某个应用规则集的整体安全效果。

| 入口 | 评估对象 | 输出 |
| --- | --- | --- |
| [prompt_injection/](prompt_injection/) | 指定的提示注入检测组件与锁定的攻击载荷、良性难例 | 召回率、误报率、ROC AUC、可用阈值与分组结果 |

仓库单元测试与集成测试验证规则加载与匹配、放行/记录/拦截结果、调用检查点、输出释放、故障处理和受保护操作。具体规则集的效果需要使用对应应用的真实工作负载评估；真实 Agent 对照评测还要求在未启用规则时存在成功攻击样本。

## 评估工具

`evals/lib/` 提供：

- `reporting.py`：不可变的单次运行目录、只追加的索引和最新结果指针；
- `metrics.py`：Detector 分类指标；
- `detectability.py`：按内容可检测性划分第三方语料。

每次评估运行都会写入一个独立目录，并更新索引和最新结果文件：

```text
data/benchmarks/<eval>/results/
  <UTC时间戳>-<eval>/report.json
  index.jsonl
  latest.json
```

结果目录位于 Git 跟踪范围外；每次运行创建独立 run 目录。
